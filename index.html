Featured Project

jayaprakashkupparaju.com — Production Website SRE Lab

Developed and operate this production website on Azure Static Web Apps as a hands-on Site Reliability Engineering lab. It combines safe software delivery, observable infrastructure, incident recovery and strict cost controls in a real public service that evolves with each phase of my learning roadmap.

Engineering outcomes

  • Automated CI checks and isolated Azure previews for pull requests
  • Protected production releases with a human approval gate
  • Live deployment metadata linking production to its exact Git commit
  • Custom domain routing through Cloudflare with managed HTTPS
  • Azure availability monitoring, telemetry and actionable email alerts
  • Tested emergency rollback with a documented source-recovery process
  • Automatic monitoring cutoff and a $10 annual budget alert guardrail

Skills demonstrated

  • CI/CD design, branch protection, automated testing and security scanning
  • Environment-scoped secrets, preview environments and release governance
  • Azure Monitor, Application Insights, Log Analytics and KQL fundamentals
  • Alert routing, incident response, rollback and runbook development
  • Bicep infrastructure as code, managed identity and least-privilege RBAC
  • Cost-aware engineering with budgets and automatic resource shutdown
